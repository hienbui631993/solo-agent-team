# Social creative references

Put examples of visuals you like here (PNG, JPG, or HTML). The designer copies the **style and feel**, not the exact design.

Included starter: `quote-card.html` (1080×1350, 4:5 portrait post). Render it to PNG:

```
scripts/render.sh templates/social-creatives/quote-card.html outputs/visuals/test.png 1080 1350
```

Common sizes:
| Format | Size |
|---|---|
| Portrait post / carousel slide | 1080×1350 |
| Square post | 1080×1080 |
| Story / Reel cover | 1080×1920 |
| Landscape / LinkedIn | 1200×627 |
