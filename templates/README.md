# Templates

Put examples of **what good looks like** here. Skills study these and copy the pattern (the "reference method").

Good things to add:
- A post that performed well (`templates/posts/`)
- An outreach message that got replies (`templates/messages/`)
- A client report you liked (`templates/reports/`)
- Your slide deck or document template, if you have one
