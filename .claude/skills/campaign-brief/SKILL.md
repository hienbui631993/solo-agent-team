# Campaign Brief

*Usually run by the **strategist** agent. Read `context/` and `sops/approval-rules.md` first.*

## Inputs
- The goal from the user (e.g. "get 3 new clients this month").
- All files in `context/`.

## Steps
1. Restate the goal as a number and a date.
2. Pick one audience segment from the customer profile.
3. Write one core message and 3 supporting points, in the customer's words.
4. Pick 1–2 channels (where this audience already is).
5. List the content and outreach pieces needed, with an owner agent for each.
6. Set the success numbers and a weekly check.

## Output
Save `outputs/strategy/campaign-brief-[name].md`. Add the pieces as tasks to `tasks/board.md`.

## Quality check
- One audience, one message. If it tries to talk to everyone, narrow it.

## Teach the user
After the output, add a short section called **Why I did it this way**: 2–3 lessons in simple English that explain the skill behind the choices. End with one short question that checks the user understood.
