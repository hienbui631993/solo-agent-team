# Lead Magnet

*Usually run by the **content-creator** agent. Read `context/` and `sops/approval-rules.md` first.*

## Inputs
- `context/customer-profile.md` and `context/offer.md`.

## Steps
1. Suggest 3 lead magnet ideas. Favor learning resources, quizzes or tools over discounts (they usually get more signups).
2. Each idea must solve one small, urgent problem and point naturally to the paid offer.
3. Draft the chosen one in full (title, sections, content, final call to action).
4. Write a short signup page text: headline, 3 bullets, button text.

## Output
Save to `outputs/content/lead-magnet-[name]/`: `lead-magnet.md` and `signup-page.md`.

## Quality check
- Can be consumed in under 10 minutes.
- Gives a real quick win, not a sales pitch.

## Teach the user
After the output, add a short section called **Why I did it this way**: 2–3 lessons in simple English that explain the skill behind the choices. End with one short question that checks the user understood.
